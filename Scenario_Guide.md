# Инструкция по написанию сценариев (XML Format)

Эта инструкция предназначена для создания сюжетных файлов `Dialog_Structured.xml` для игрового движка.

## Основная структура

Весь сценарий должен быть обернут в корневой тег `<game>`. Внутри него располагаются сцены (диалоги), описываемые тегом `<dialog>`.

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<game>
    <dialog id="1" nextScene="2" background="..." music="...">
        <!-- Шаги диалога -->
    </dialog>
    
    <dialog id="2" ...>
        <!-- Шаги диалога -->
    </dialog>
</game>
```

---

## 1. Сцена (`<dialog>`)

Каждый блок сюжета — это сцена.

**Атрибуты:**
*   `id` (обязательно): Уникальное число (ID сцены).
*   `nextScene` (обязательно): ID следующей сцены, на которую перейдет игра после окончания текущей. Укажите `-1`, если это конец ветки.
*   `background` (опционально): Путь к фоновому изображению (от корня, например `lib/Scene/Bg.png`).
*   `music` (опционально): Путь к музыке (например `lib/sound/Track.mp3`).

---

## 2. Затемнение с текстом (`<overlay>`)

Полноэкранное затемнение с текстом по центру (DimOverlay). Удобно для заставок и начала истории: по клику «Далее» затемнение скрывается и показывается следующий кадр.

**Синтаксис:**
```xml
<overlay text="Глава 1. Начало истории."/>
```

**Атрибуты:**
*   `text` (обязательно): Текст, отображаемый по центру на затемнённом фоне.

Можно ставить в начале сцены (первым элементом в `<dialog>`) или в любом месте. Один кадр = одно нажатие «Далее» (сначала показывается overlay, по клику — переход к следующему кадру).

---

## 3. Реплика / Кадр (`<character>`)

Каждый шаг внутри сцены — это тег `<character>`. Он содержит текст диалога и команды.

**Атрибуты:**
*   `name`: Имя говорящего (отображается в интерфейсе).
*   `color`: Цвет имени (например: `WHITE`, `GREEN`, `RED`, `#FF0000`). Если не указан — берётся из `Person.xml`.
*   `overlay` (опционально): Текст для полноэкранного затемнения в этом кадре; затемнение показывается поверх сцены, по клику скрывается и остаётся реплика в табличке.
*   `voice` (опционально): Путь к озвучке реплики.
*   `sound` (опционально): Путь к разовому звуковому эффекту кадра (скрип двери, выстрел). Звук проигрывается заново при возврате на кадр — это эффект, а не состояние.

**Пример:**
```xml
<character name="Элейн" color="GREEN">Привет! Рада тебя видеть.</character>
```

---

## 4. Команды и Анимации (`<command>`)

Чтобы персонаж появился, ушел или сменился фон **во время этой реплики**, добавьте тег `<command>` **внутрь** тега `<character>`.

**Синтаксис:**
```xml
<command type="..." action="..." target="..." value="..."/>
```

### Типы команд:

#### A. Управление персонажами (`type="character"`)
Требует атрибут `target` (имя персонажа, как в `Person.xml`).

| Action | Описание | Нужен `value`? |
| :--- | :--- | :--- |
| `showPerson` | Показать персонажа (появляется плавно или мгновенно) | Да (Название позы: "Stay", "Smile") |
| `removeFromScene` | Плавно убрать персонажа со сцены | Нет |
| `move_Left` | Переместить персонажа влево | Нет |
| `move_Right` | Переместить персонажа вправо | Нет |
| `move_Center` | Переместить персонажа в центр | Нет |

Команды состояния (тоже `type="character"`) меняют прогресс игрока. Они попадают
в историю и в сохранение, поэтому при «Назад» состояние корректно откатывается.

| Action | Описание | `target` | `value` |
| :--- | :--- | :--- | :--- |
| `SetFlag` | Установить флаг прогресса | Имя флага | `true` / `false` |
| `SetReputation` | Задать репутацию персонажа | Имя персонажа | Число 0–100 |
| `AppendReputation` | Увеличить репутацию | Имя персонажа | Число |
| `ReduceReputation` | Уменьшить репутацию | Имя персонажа | Число |
| `SetChoice` | Записать выбор/улику игрока | Ключ выбора | Значение |
| `startTitres` | Запустить финальные титры | — | — |

Исторические написания `AppendReputathion` и `ReduceReputathion` тоже поддерживаются.

**Пример:**
```xml
<character name="Маркус" color="GREY">
    <command type="character" action="SetFlag" target="knows_fact_1" value="true"/>
    <command type="character" action="ReduceReputation" target="Маркус" value="10"/>
    Не стоило тебе этого говорить.
</character>
```

#### B. Управление фоном (`type="background"`)

| Action | Описание | Нужен `value`? |
| :--- | :--- | :--- |
| `changebackground` | Сменить фон на новый | Да (Путь к файлу) |

#### C. Переключение темы интерфейса (`type="theme"`)

Меняет стиль всего интерфейса (главное меню, загрузка, панели, кнопки). Тема сохраняется в настройках и в сейв; при загрузке сейва восстанавливается.

| Атрибут | Описание |
| :--- | :--- |
| `value` | Идентификатор темы: `hitech` (хайтек), `classic` (классический, тёплые тона), `walk` (прогулка, природа), `dnd` (кора, листва, лес), `fire` (огненный). |

**Пример:** при входе в «прогулку» по игре переключить стиль на природу:
```xml
<character name="Автор" color="WHITE">
    <command type="theme" value="walk"/>
    Ты выходишь из базы в зелёную зону.
</character>
```

## Примеры использования

### Пример 1: Начало с затемнением и вводом имени
```xml
<dialog id="1" nextScene="2" background="lib/Scene/Scene1/BlackScene.png" music="">
    <overlay text="Глава 1. Начало истории."/>
    <character name="{playerName}" color="WHITE">
        <command type="input" key="playerName" prompt="Введите имя:"/>
        Ты заходишь в темный лес.
    </character>
    <character name="Автор" color="WHITE">Рад тебя видеть, {playerName}!</character>
</dialog>
```
Сначала затемнение; по клику — открывается окно «Введите имя:»; введённое имя сохраняется и подставляется в имя персонажа и в текст как `{playerName}`.

### Пример 2: Простой диалог
```xml
<dialog id="10" nextScene="11" background="lib/Scene/Forest.png">
    <character name="Автор" color="WHITE">Ты заходишь в темный лес.</character>
    <character name="Герой" color="BLUE">Тут жутковато...</character>
</dialog>
```

### Пример 3: Появление и движение
```xml
<dialog id="20" nextScene="-1">
    <!-- Персонаж Лиза появляется по центру -->
    <character name="Автор" color="WHITE">
        <command type="character" action="showPerson" target="Liza" value="Stay"/>
        Вдруг из кустов выходит Лиза.
    </character>

    <!-- Лиза говорит и отходит вправо -->
    <character name="Liza" color="GREEN">
        <command type="character" action="move_Right" target="Liza"/>
        Не стой на дороге, отойди!
    </character>
</dialog>
```

### Важные правила для ИИ:
1.  **Пути к файлам:** Всегда указывай полные относительные пути (начинаются с `lib/`).
2.  **Имена:** Имена в `target` должны совпадать с именами файлов/папок персонажей (Liza, Elein, Marcus).
3.  **Позы:** Названия поз в `value` должны существовать в конфиге персонажей (обычно это: Stay, Smile, Angry, Normal).
4.  **Логика:** Не пытайся двигать персонажа (`move_Left`), если перед этим не показал его командой `showPerson`.
5.  **Начало сцены:** Чтобы начать с затемнения и текста (например, «Глава 1»), первым элементом в `<dialog>` поставь `<overlay text="Глава 1. Начало истории."/>`.
6.  **Имя игрока:** Добавь кадр с `<command type="input" key="playerName" prompt="Введите имя:"/>` и в имени или тексте используй `{playerName}` — значение сохранится в сейв и подставится везде.
